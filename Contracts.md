# Contracts & Standards

## Reglas de Desarrollo
1. **Inmutabilidad:** Las entidades deben usar DTOs para la comunicación externa.
2. **Validaciones:** Usar Bean Validation (JSR 303).
3. **Manejo de Errores:** Implementar un GlobalExceptionHandler para respuestas consistentes.
4. **Base de Datos:** Los nombres de tablas en plural y snake_case.

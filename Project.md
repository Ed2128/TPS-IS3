# Project: Sistema de Gestión de Eventos Académicos (SGEA)

## Visión General
Plataforma web para organizar cursos, jornadas y congresos, facilitando la inscripción, acreditación y certificación de participantes.

## Stack Tecnológico Forzado
- **Backend:** Java 21 con Spring Boot 3.x.
- **Persistencia:** PostgreSQL con JPA/Hibernate.
- **Documentación API:** Swagger/OpenAPI.
- **Frontend:** Next.js (React).
- **Estilo de Código:** Uso obligatorio de Lombok y arquitectura por capas (Controller, Service, Repository).
